AI Course Assistant 2.1.0

* Provides course-aware guidance using Google Gemini or OpenAI.
* Supports Moodle 5.0 through 5.2.
* Offers top-right, bottom-right, bottom-center, bottom-left, course-header, and static full-page placements.
* Keeps non-static chats on the Moodle course page without narrowing or moving course content.
* Lets users make the in-page chat movable and drag it anywhere within the visible browser area.
* Restores the open chat, saved position, and active conversation when users navigate within the same course.
* Keeps the static full-page assistant on a separate page with a Return to course control.
* Provides conversation history, copy, download, speech input, and read-aloud controls.
* Keeps suggested actions and the compact composer inside the chat at every supported width.
* Provides Read aloud for the welcome message as well as subsequent assistant responses.
* Provides administrator-selected assistant names, colors, icons, response languages, providers, and models.
* Enforces Moodle capabilities, session-key protection, privacy metadata, and role-aware response policies.
